# WhatDaysWork

WhatDaysWork is a group scheduling application designed to make planning events easier for everyone involved. Users can create shared calendars, invite participants, and collaboratively mark their availability. The app highlights the days that work best for all participants, simplifying the process of organizing group events like vacations, meetings, or outings.

## What I Learned

This project was a valuable learning experience that helped me grow as a developer. Here are some of the key takeaways:

- **Backend Development with Prisma**: I learned how to use Prisma as an ORM for managing a PostgreSQL database. This included defining models, handling migrations, and implementing complex relationships between entities like users, calendars, and availability.

- **Authentication with Google OAuth**: I implemented Google OAuth for user authentication using Passport.js. This taught me how to integrate third-party authentication providers and manage JWT-based sessions.

- **Frontend Development with React**: I built the frontend using React, focusing on creating reusable components, managing state with hooks, and implementing routing with React Router.

- **API Integration**: I gained experience in designing and consuming RESTful APIs, including handling authentication headers and managing API calls with Axios.

- **FullCalendar Integration**: I integrated FullCalendar to provide an interactive calendar interface, allowing users to view and manage availability visually.

- **Hosting and Deployment**: I deployed the app to Render, learning how to configure environment variables, manage build processes, and ensure the app runs smoothly in a production environment.

## Features

- **User Authentication**: Secure login with Google OAuth.
- **Shared Calendars**: Create and manage calendars with multiple participants.
- **Availability Tracking**: Mark and view availability for specific dates.
- **Invitations**: Send and manage calendar invitations.
- **Interactive UI**: A user-friendly interface built with React and FullCalendar.

This project was a great opportunity to combine multiple technologies and build a full-stack application from scratch. I'm proud of what I accomplished and excited to continue learning and improving!
